# Выпуск v44 — что сделать владельцу

Порядок: **сайт → Worker → проверка вдвоём.** Главное в v44:

- видео у обоих: если оба включали камеру одновременно, у одного из двоих
  видео собеседника оставалось закрыто заглушкой, хотя кадры шли. Теперь
  видео показывается, как только приходят кадры;
- код разбит на модули: `app.js` 5907 → 3607 строк, `chat.js` 6632 →
  4132 строки, поведение не менялось;
- Worker: лимиты на создание чатов, кодов, ссылок, бэкапов, регистрацию
  номера, файлы и выдачу TURN хранятся в Durable Object `Guard` и не
  обнуляются при перезапуске. Слишком большие запросы получают 413 до
  чтения тела;
- второстепенный текст стал контрастнее.

Подробно — [CHANGELOG.md](CHANGELOG.md). Форматы данных и протокол звонка
не менялись: v44 звонит и переписывается с v43–v41.

## 1. Публикация сайта

Выкладывать только в `ZVONochek/zvonochek.github.io` (сайт
https://zvonochek.github.io/). Старый репозиторий `qwkejkqwje1/zvonochek` —
архив, туда ничего не загружайте.

**Вариант А — git (рекомендую).**

```bash
git clone https://github.com/ZVONochek/zvonochek.github.io && cd zvonochek.github.io
git apply --binary ../zvonochek-v44.patch
git add -A && git commit -m "44v" && git push
```

**Вариант Б — веб-интерфейс GitHub.** «Add file» → «Upload files» →
перетащите содержимое архива → «Commit changes». В v44 ни один файл не
удаляется, только добавляются новые (`audio-engine.js`, `bridge.js`,
`chat-*.js` и др., `worker/guard.js`, `tests/guard.test.mjs`), поэтому
загрузки достаточно.

Проверка: `https://zvonochek.github.io/version.json` → `{"v":44}`
(GitHub Pages обновляется за 1–2 минуты). Открытое приложение само
перезагрузится, под названием будет «v44», кэш Service Worker —
`zvonochek-v44`. Во вкладке **Actions** — прогон «tests».

## 2. Worker — нужен деплой

Сайт v44 работает и со старым Worker v41. Новые лимиты включатся только
после деплоя. Из корня репозитория:

```bash
npx wrangler deploy
```

Миграция `v5` создаст новый класс Durable Object `Guard`. Существующие
комнаты, номера, чаты и бэкапы не затрагиваются. Durable Objects на SQLite
входят в бесплатный тариф Workers, карта не нужна.

Проверка: `https://<ваш-worker>/health` → `"v": 44, "guard": true`.

В `wrangler.toml` должны остаться оба адреса сайта:
`ALLOWED_ORIGINS = "https://qwkejkqwje1.github.io,https://zvonochek.github.io"`.
При деплое значения из `[vars]` заменяют то, что задано в панели
Cloudflare. Без нового адреса сайт на zvonochek.github.io потеряет доступ к
Worker. Старый адрес не убирайте, пока архивная v41 там работает.

Если после деплоя что-то не так, откатите Worker в панели Cloudflare →
Worker → **Deployments** → предыдущая версия → «Rollback». Сайт v44
продолжит работать.

## 3. Проверка вдвоём (15 минут)

Нужны два устройства с v44, лучше в разных комнатах или в наушниках. Роли в
звонке выпадают случайно, поэтому каждую проверку повторите 3–4 раза,
перезагружая страницу перед звонком.

1. **Оба включают камеру одновременно (новое в v44).** Позвоните без камер.
   По счёту «три» оба нажимают «Камера». Через 1–3 с у **каждого** видно
   видео собеседника, а не заглушку. Затем оба одновременно выключают
   камеру: у обоих снова заглушка. Повторите, начав звонок с уже
   включёнными камерами у обоих.
2. **Камера только у одного.** Звонок соединяется за 1–3 с, видео
   доходит. В «Диагностика» «Маршрут звонка» начинается с «напрямую» или
   «через TURN». Поменяйтесь: камера у второго.
3. **Чат и QR (2 минуты).** В чате отправьте подряд 5–6 коротких
   сообщений как можно быстрее, у собеседника все по порядку. Отправьте
   файл и голосовое. Создайте приглашение в чат по коду и по QR — второй
   телефон входит. Это проверяет код, перенесённый в новые модули.
4. **TURN на вашем устройстве.** «Настройки» → «Маршрут и обход
   блокировок» → «Режим соединения» → «Скрыть мой IP — только через TURN»,
   позвоните с камерой у обоих. Видео у обоих. В «Диагностика» в строке
   «Мои маршруты» — «через TURN» с числом больше нуля. Если нет, TURN-серверы
   из `config.js` из вашей сети недоступны: нажмите «Скопировать отчёт» и
   пришлите. После проверки верните «Авто».

Видео через мост не передаётся: мост несёт только голос. Если звонок ушёл
в мост, под именем собеседника написано «Видео появится, когда соединение
станет прямым».

## 4. Звонки при закрытом приложении — на каждом устройстве

1. **Android:** «Мой номер» → «Push-уведомления о звонках» (или кнопка
   «Включить» на плашке во вкладке «Звонки») → разрешить. На Xiaomi,
   Huawei, Honor и Samsung с агрессивной экономией батареи исключите
   Chrome из оптимизации батареи, иначе push может опаздывать.
2. **iPhone:** сначала «Поделиться» → «На экран Домой», откройте
   ZVONochek с иконки и только потом включайте уведомления (iOS ≥ 16.4; в
   Safari-вкладке push на iPhone не работает).
3. **ПК:** браузер должен быть запущен (вкладку можно закрыть).

На **выключенный** телефон звонок не дойдёт ни в одном мессенджере.
Звонок ждёт, только пока идёт вызов (до 90 с), потом попадает в
«Пропущенные» (хранятся 24 ч).

## 5. Второе устройство (телефон + ПК)

Как в v39: на новом устройстве «Мой номер» → «Подключить к моему
профилю»; на основном — «Мои устройства» → «Подключить устройство» → QR
или код → сверить 4 слова. Код и QR никому не пересылайте. Подключать,
отвязывать, менять и гасить номер можно только на основном устройстве
(или там, где введена фраза восстановления); с v41 это проверяет и
сервер. Украли устройство: на основном «Отвязать», затем «Сменить номер».

## 6. TURN — крайнее средство

Без изменений с v40. Звонок начинается без TURN. Логины из `config.js`
включаются, только если прямой путь не поднялся за 6 с (пока ICE явно
продвигается, ждём до 14 с), соединение упало, после смены сети не
нашлось прямого пути или выбран режим «только TURN». Логины видны всем в
публичном репозитории. Если чужие выберут квоту, зарегистрируйтесь
бесплатно на metered.ca или expressturn.com и впишите новые логины в
`config.js` или в секреты Worker (`TURN_URLS`, `TURN_USERNAME`,
`TURN_CREDENTIAL`, см. [worker/README.md](worker/README.md)).

## 7. Откат

- **Сайт:** `git revert` коммита «44v» или загрузка архива v43. Форматы
  данных v44 не меняет: настройки, профили и переписка совместимы в обе
  стороны.
- **Worker:** «Rollback» в панели Cloudflare (см. §2). Класс `Guard`
  останется, но старый Worker к нему не обращается.

Перед публикацией разработчику: `npm ci && npm test`, при наличии
Chromium — `npm run worker:dev` и `npm run e2e`. То же самое делает CI
(`.github/workflows/ci.yml`) на каждый push.
