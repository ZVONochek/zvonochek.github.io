# Выпуск v43 — что сделать владельцу

Порядок: **сайт → проверка вдвоём.** Worker не меняется. Главное в v43:

- снова видны QR-коды: в «Пригласить собеседника» и в приглашении в чат.
  С v36 вместо них было пустое белое место;
- QR-код своего номера: «Мой номер» → «QR-код» рядом с «Поделиться»;
- при быстрой отправке подряд в чате больше не пропадают сообщения;
- в звонке через мост написано, что видео появится, когда соединение
  станет прямым: мост передаёт только голос;
- «Диагностика» больше не считает маршруты собеседника дважды.

Всё, что было в v42 (звонок с камерой у одного из двоих, мост 2.0, 429 от
Nostr), остаётся — [AUDIT-v42.md](AUDIT-v42.md). Форматы данных и
протокол звонка не менялись: v43 звонит и переписывается с v42 и v41.

## 1. Worker — без изменений

`https://<ваш-worker>/health` → `"v": 41`. Деплоить не нужно.

Если всё же будете деплоить (`npx wrangler deploy`), в `wrangler.toml`
должны остаться оба адреса сайта:
`ALLOWED_ORIGINS = "https://qwkejkqwje1.github.io,https://zvonochek.github.io"`
(ваш коммит `b954896`). При деплое значения из `[vars]` заменяют то, что
задано в панели Cloudflare. Без нового адреса в этом списке сайт на
zvonochek.github.io потеряет доступ к Worker. Старый адрес не убирайте,
пока там остаются люди: архивная v41 тоже работает через этот Worker.

## 2. Публикация сайта

Выкладывать только в `ZVONochek/zvonochek.github.io` (сайт
https://zvonochek.github.io/). Старый репозиторий `qwkejkqwje1/zvonochek` —
архив, туда ничего не загружайте. Сайт по старому адресу останется на v41.
Звонки между v41 и v43 работают (AUDIT-v42.md, §6), но ошибка с камерой у
одного на старом адресе сохраняется. Если кто-то ещё звонит со старого
адреса, попросите его открыть новый.

**Вариант А — git (рекомендую).**

```bash
git clone https://github.com/ZVONochek/zvonochek.github.io && cd zvonochek.github.io
git apply --binary ../zvonochek-v43.patch
git add -A && git commit -m "43v" && git push
```

**Вариант Б — веб-интерфейс GitHub.** «Add file» → «Upload files» →
перетащите содержимое архива → «Commit changes». В v43 ни один файл не
удаляется, а скрытые `.github/` и `.gitignore` не менялись, поэтому
загрузки достаточно.

Проверка: `https://zvonochek.github.io/version.json` → `{"v":43}`
(GitHub Pages обновляется за 1–2 минуты). Открытое приложение само
перезагрузится на новую версию, под названием будет «v43». Service Worker
сменит кэш на `zvonochek-v43`. Во вкладке **Actions** —
прогон «tests».

## 3. Проверка вдвоём (15 минут)

Нужны два устройства с v43, лучше в разных комнатах или в наушниках.
Роли в звонке (кто делает предложение, кто отвечает) выпадают случайно,
поэтому каждую проверку повторите 3–4 раза, перезагружая страницу перед
звонком.

0. **QR и чат (новое в v43, 2 минуты).** «Звонки» → «Создать» →
   «QR-код» — виден QR, телефон его считывает. «Мой номер» → «QR-код» —
   QR своего номера, со второго телефона открывается ваш номер. В чате
   отправьте подряд 5–6 коротких сообщений как можно быстрее (набрали —
   Enter — сразу следующее). У собеседника должны быть все, по порядку.

1. **Камера только у одного.** У одного камера включена, у другого нет.
   Звонок соединяется за 1–3 с, видео доходит. Нажмите «Диагностика»:
   «Маршрут звонка» начинается с «напрямую» или «через TURN», а не
   «Зашифрованный Мост через Сигналинг». Затем поменяйтесь: камера у
   второго.
2. **Камера посреди звонка.** Начните без камер, затем включите камеру у
   одного, потом у второго. Видео появляется у собеседника за пару секунд.
3. **Мост 2.0** (оба на Chrome или другом браузере на Chromium; в Safari
   останется мост 1.0). У обоих: «Настройки» → «Маршрут и обход
   блокировок» → «Режим соединения» → «Только мост через сигнал (без
   TURN/UDP)». Позвоните. В «Диагностика» → «Журнал событий» должна быть
   строка «Мост 2.0 (WebCodecs Opus, кадры 20 мс) включён» и не должно
   быть «Мост 2.0: ошибка кодировщика». Голос слышен в обе стороны.
   После проверки верните «Авто».
4. **TURN на вашем устройстве.** В живом звонке у вашего устройства не
   было ни одного маршрута через TURN, у моего — 6. Выберите «Режим
   соединения» → «Скрыть мой IP — только через TURN» и позвоните. В
   «Диагностика» в строке «Мои маршруты» должно быть «через TURN» с
   числом больше нуля. Если этой части нет, TURN-серверы из `config.js`
   из вашей сети недоступны. Тогда, если прямой путь не встанет, звонок
   уйдёт в мост. Нажмите «Скопировать отчёт» и пришлите его. После
   проверки верните «Авто».

## 4. Звонки при закрытом приложении — на каждом устройстве

1. **Android:** «Мой номер» → «Push-уведомления о звонках» (или кнопка
   «Включить» на плашке во вкладке «Звонки») → разрешить. На Xiaomi,
   Huawei, Honor и Samsung с агрессивной экономией батареи исключите
   Chrome из оптимизации батареи, иначе push может опаздывать.
2. **iPhone:** сначала «Поделиться» → «На экран Домой», откройте
   ZVONochek с иконки и только потом включайте уведомления (iOS ≥ 16.4; в
   Safari-вкладке push на iPhone не работает).
3. **ПК:** браузер должен быть запущен (вкладку можно закрыть).

На **выключенный** телефон звонок не дойдёт ни в одном мессенджере.
Звонок ждёт, только пока идёт вызов (до 90 с), потом попадает в
«Пропущенные» (хранятся 24 ч).

## 5. Второе устройство (телефон + ПК)

Как в v39: на новом устройстве «Мой номер» → «Подключить к моему
профилю»; на основном — «Мои устройства» → «Подключить устройство» → QR
или код → сверить 4 слова. Код и QR никому не пересылайте. Подключать,
отвязывать, менять и гасить номер можно только на основном устройстве
(или там, где введена фраза восстановления); с v41 это проверяет и
сервер. Украли устройство: на основном «Отвязать», затем «Сменить номер».

## 6. TURN — крайнее средство

Без изменений с v40. Звонок начинается без TURN. Логины из `config.js`
включаются, только если прямой путь не поднялся за 6 с (пока ICE явно
продвигается, ждём до 14 с), соединение упало, после смены сети не
нашлось прямого пути или выбран режим «только TURN». Логины видны всем в
публичном репозитории. Если чужие выберут квоту, зарегистрируйтесь
бесплатно на metered.ca или expressturn.com и впишите новые логины в
`config.js` или в секреты Worker (`TURN_URLS`, `TURN_USERNAME`,
`TURN_CREDENTIAL`, см. [worker/README.md](worker/README.md)).

## 7. Откат

- **Сайт:** `git revert` коммита «43v» или загрузка архива v42. Форматы данных v43 не меняет: настройки, профили и
  переписка совместимы в обе стороны.
- **Worker:** не менялся.

Перед публикацией разработчику: `npm ci && npm test`, при наличии
Chromium — `npm run worker:dev` и `npm run e2e`. То же самое делает CI
(`.github/workflows/ci.yml`) на каждый push.
